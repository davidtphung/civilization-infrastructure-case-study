# Civilization Infrastructure Case Study

**Live Site:** https://davidtphung.github.io/civilization-infrastructure-case-study/

Interactive case study exploring AI data center infrastructure as civic architecture.

## Thesis

Demystify the AI data center as anatomy + beauty + civic honesty, then slide that programming into the home so automation creates time for sacred friction (ritual, kids, craft), not zero domesticity.

## Site Features

- **6 Scenario Plates**: Visualization renders exploring infrastructure programming
- **Interactive Lightbox**: Click plates for full-size view with captions
- **PES Analysis**: Political, Economic, and Social commentary tabs
- **Programming Flow**: Sequence from DC infrastructure to sacred domestic moments
- **Action Board**: Project tracking

## Scenario Plates

- **C0: House of Future** - Progression: Infrastructure → Automation → Sacred Domestic
- **C1: Case Study Railway** - I-beam structure as robot railway
- **C2: Pompidou Jugular** - Exposed infrastructure as civic honesty
- **C3: DC + Apartments** - Mixed-use with datacenter podium
- **C7: Home Rack Niche** - Domestic server room in utility void
- **C8: Wind Tower Mix** - Passive + mechanical cooling hybrid
